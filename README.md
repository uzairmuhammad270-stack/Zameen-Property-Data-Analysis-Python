# Zameen Property Data Analysis – Python

## Overview

A **Python-based exploratory data analysis project** using a scraped Zameen property dataset. The project focuses on data cleaning, transformation, analysis, and visualization to uncover patterns and trends in the real estate market.

## Project Work

* Cleaned and processed the dataset using **Pandas**
* Handled missing values, duplicates, and data inconsistencies
* Performed exploratory data analysis
* Created **Pivot Tables using Pandas** for summarized analysis
* Developed visualizations using **Matplotlib** and **Seaborn**
* Analyzed property-related trends and patterns

## Tools & Libraries

**Python | Jupyter Notebook | Pandas | Matplotlib | Seaborn**

## Objective

To transform scraped real estate data into a **clean, structured, and insightful dataset** and visualize key property market trends through Python-based analysis.
